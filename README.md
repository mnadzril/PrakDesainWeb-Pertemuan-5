# Tugas Pertemuan 5

## 1. Rincian File

Proyek ini merupakan hasil praktikum/tugas untuk Pertemuan 5. File ini berisi implementasi desain antarmuka web sederhana berdasarkan rancangan yang telah dibuat sebelumnya, memastikan tampilan responsif pada perangkat desktop maupun mobile.

## 2. Dasar Teori

> **Wireframe**
> Wireframe adalah kerangka dasar atau sketsa awal dari sebuah halaman web (atau aplikasi) yang menunjukkan struktur visual, tata letak elemen, navigasi, dan konten informasi. Wireframe biasanya dibuat dalam bentuk hitam-putih tanpa elemen desain grafis (seperti warna atau tipografi) untuk fokus pada fungsi dan pengalaman pengguna (User Experience/UX).

## 4. Yang Dipakai

Berikut adalah elemen-elemen HTML dan properti CSS yang digunakan dalam proyek ini:

**Elemen HTML:**

- `<html>`, `<head>`, `<body>` (Struktur dasar)
- `<header>`, `<nav>`, `<main>`, `<footer>` (Semantic tag)
- `<div>`, `<section>` (Wadah/kontainer)
- `<h1>` hingga `<h6>`, `<p>` (Teks)
- `<img>` (Gambar)
- `<a>` (Tautan)
- `<ul>`, `<li>` (Daftar/List)

**Properti CSS:**

- `margin`, `padding`, `box-sizing` (Box model)
- `display: flex;` / `display: grid;` (Sistem layout)
- `color`, `background-color`, `font-family`, `font-size` (Tipografi dan warna)
- `width`, `height`, `max-width` (Dimensi)
- `@media screen and (max-width: ...)` (Media queries untuk responsivitas)

## 6. Kesimpulan

Proyek pada pertemuan 5 ini berhasil mengimplementasikan rancangan wireframe ke dalam bentuk kode HTML dan CSS. Melalui tugas ini, pemahaman mengenai penggunaan tag semantik HTML dan sistem layout CSS (seperti Flexbox/Grid) menjadi lebih baik, serta memastikan halaman web dapat beradaptasi dengan baik pada berbagai ukuran layar (responsif).
